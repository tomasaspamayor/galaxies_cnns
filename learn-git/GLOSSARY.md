# Git Glossary

The canonical vocabulary for this workspace. Every lesson and reference document
uses these exact terms. Definitions are kept tight: they say what the term **is**,
not how to do it.

Terms are added here only once you have demonstrated you understand them (usually
via a lesson quiz or a practice exercise), so this file records compressed
knowledge rather than acting as a dictionary to read ahead.

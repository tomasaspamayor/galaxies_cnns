# Teaching Notes

Working scratchpad for teaching preferences and observations. Not a lesson and not
a learning record.

## Learner profile
- Beginner: comfortable with `clone` / `add` / `commit` / `push`, little beyond.
- Physics/data-analysis student; project = galaxies + CNNs (`galaxies_cnns`).
- Environment: **Windows 11 + PowerShell**, Git installed; edits in VS Code / Python.
- Prefers short, self-contained sessions.

## Preferences
- Wants **both**: the teach-workspace course (`lessons/`, `reference/`) **and** the
  `learn.md` research brief (`learning/git/summary.md` + `notes.md` + `sources.md`).
- Mission framed as "manage my research/data project confidently" — keep every
  lesson grounded in a real research workflow, not toy examples.

## Environment gotchas
- Path contains spaces and accents (`F Í S I C A`). Quote paths in commands; when
  pointing the learner at CLI examples, remember PowerShell, not bash.
- The repo already has a real active branch `dev-nacho` with staged + untracked
  changes — a perfect live lab for the three-trees lesson.

## Open threads
- Introduce `git switch` / `git restore` (2.23+) as the modern spelling, but note
  `checkout` because they'll meet it everywhere.
